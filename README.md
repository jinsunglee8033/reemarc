# Reemarc
**Role**: Lead Web Developer

## Overview
Reemarc is a comprehensive platform for transparent orthodontic patients, providing seamless interaction between patients, dental professionals, and the platform. The service is offered through both a web application and a mobile app, which communicate via APIs to ensure smooth data transfer.

Patients can schedule appointments with dental clinics through the app, where they are provided with personalized orthodontic aligners based on their specific treatment plans. The app also sends notifications to patients about aligner replacement schedules, helping them stay on track with their treatment.

The web portion of the project, which I led the development for, provides a robust and scalable environment for managing patient and clinic data, tracking treatment progress, and offering administrative features.

## Key Achievements
- **Cross-platform Integration**: Successfully integrated the web and mobile platforms via APIs, ensuring seamless data synchronization and functionality between both platforms.
- **Patient Treatment Management**: Developed a system for managing patient appointments and aligner replacement schedules, ensuring patients remain compliant with their treatment.
- **Efficient Communication**: Enabled direct communication between patients and clinics, streamlining appointment scheduling and treatment monitoring.
- **Notifications**: Implemented an automated notification system that reminds patients of their next aligner replacement, ensuring better treatment adherence.

## Responsibilities
- Led the development of the web platform, from system architecture to front-end implementation.
- Coordinated data exchange between the mobile app (developed with Flutter) and the web platform through APIs.
- Developed and integrated patient management features, including treatment scheduling, clinic interactions, and notifications.
- Ensured a smooth user experience by implementing responsive design and intuitive interfaces.

## Technologies
- **Backend**: PHP, Laravel (8), MySQL  
- **Frontend**: JavaScript, Bootstrap, jQuery, HTML5, CSS3  
- **Mobile App**: Flutter  
- **Architecture**: MVC  

## Outcome
- Successfully delivered a fully integrated platform that connects patients and clinics, improving patient adherence to orthodontic treatment.
- Currently maintaining and improving the web platform, ensuring continuous updates and optimizations.
